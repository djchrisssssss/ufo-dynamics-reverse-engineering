## 3. 驗證方法

### 第一層 — 來源識別

每筆紀錄皆標明可引用之來源。來源類別與主張支持度分開評估：官方文件對「機構報告了什麼」具權威性，而同儕審查實驗僅支持其實際檢驗之系統與條件範圍。

### 第二層 — 主張與計算審查

1. **來源定位** — 檢查書目身分與穩定識別碼。
2. **主張支持** — 檢視來源是否確實包含被引用之命題。
3. **計算重現** — 凡 repo 自行推導之數值，重新計算公式、輸入、單位與算術。
4. **狀態分類** — 分別記錄實證量測、理論／模型相依結果，或推測性外推。

目前之 `verified` 布林值表示該紀錄已通過 repo 之來源交叉檢查，**並不**代表獨立實證確認。本次審核重現了第 3 節之算術，並修正卡西米爾基準值與 Pfenning–Ford 結果之詮釋。

### 第三層 — JSON Schema 與跨檔案強制驗證

所有統計檔案均依 `data/schemas/statistics-schema.json` 驗證：
- ID 格式：`^(s0[1-9]|sA[1-4])-[0-9]{3}$`
- 必填欄位：`id`、`metric`、`value`、`unit`、`date`、`source`、`confidence`、`verification_status`、`verified`、`verification_note`
- 信心等級：`high`、`moderate`、`low`
- 驗證狀態：`verified`、`theoretical`、`speculative`
- ISO 日期與結構化來源 URI 依 JSON Schema Draft 2020-12 進行格式檢查
- 統計資料 ID 必須跨檔案唯一，且須同時符合宣告之章節與檔名
- 英文與繁體中文之註記清單各自必須完整，且出現次數須一致

## 7. 信心評估方法

依循 ICD 203（情報社群指令 203，〈分析標準〉）：

| 等級 | 定義 |
|------|------|
| **高度** | 已建立之物理學、廣泛實驗驗證及廣泛共識 |
| **中度** | 理論上健全、具部分實驗支持，並應用於新情境 |
| **低度** | 數學上一致但未經驗證、資料有限或屬推測性外推 |

驗證狀態標記：

- **[已驗證]** — 經實驗確認且已有同儕審查文獻；或就觀測與政策事實而言，記載於具權威性之第一手政府紀錄
- **[理論性]** — 數學上一致，但尚未經實驗驗證
- **[推測性]** — 超越既有理論之假設性外推；無數學證明或實驗基礎
- **[評估性]** — 作者依所引來源作出之分析判斷；本身並非實驗或同儕審查結果

## 8. 已知限制

1. **自動化 HTTP 檢查僅屬觀測性質** — 有效之官方或 DOI 端點可能對腳本請求返回 HTTP 403、429 或暫時性錯誤。必要之 CI 僅離線驗證已儲存之登錄資料；即時檢查另行執行。
2. **DIRD 內容驗證** — 個別 DIRD 之技術主張未經獨立驗證；DIRD 屬委託撰寫之分析，而非同儕審查之證據。
3. **metadata 狀態並非實證重現** — 42/45 之數字記錄的是 repo 之來源檢查，不得解讀為 42 項經獨立重現之實驗或已驗證之物理主張。
4. **NIF 資料時效性** — 核融合進展更新迅速。所述紀錄已對照 LLNL 於 2026-08-02 可取得之資訊檢查。
5. **USS Nimitz 加速度** — 詳細雷達航跡並未公開；所引加速度為依據報告輸入之模型結果，並非經校準之量測。
6. **訂閱來源** — 部分 DOI 連結論文需期刊訂閱方能完整存取。
7. **註冊表覆蓋範圍** — URL 註冊表屬抽查性質，不能保證所有引用來源在各地區或網路環境下皆可直接瀏覽。
